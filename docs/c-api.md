# C API (`libplymouth_3dboot`)

The C API wraps the Rust library for C callers such as the Plymouth splash
plugin. The header is
[`crates/plymouth-3dboot-capi/include/plymouth-3dboot.h`](../crates/plymouth-3dboot-capi/include/plymouth-3dboot.h).
It is generated by cbindgen and committed; `just check` fails when it changes
unexpectedly. Build and install with cargo-c:

```sh
cargo cbuild -p plymouth-3dboot-capi --release          # into target/
cargo cinstall -p plymouth-3dboot-capi --release --prefix /usr --destdir "$DESTDIR"
```

This installs `libplymouth_3dboot.so.0` (plus the `.so` symlink and `.a`),
`plymouth-3dboot.h` and `plymouth-3dboot.pc`. Link with
`pkg-config --cflags --libs plymouth-3dboot`.

## Example

```c
#include <plymouth-3dboot.h>

p3b_model *model = NULL;
if (p3b_model_load_file("/usr/share/plymouth/themes/n64/n64.dae", &model) != P3B_STATUS_OK) {
    fprintf(stderr, "load: %s\n", p3b_last_error());
    return;
}
if (p3b_model_clip_count(model) == 0)
    p3b_model_add_turntable(model, 0, 1, 0, 6.0f);   /* spin about +Y */

p3b_render_options options = p3b_render_options_default();
options.background[3] = 0;                            /* transparent */
p3b_renderer *renderer = NULL;
p3b_renderer_new(model, 0, width, height, &options, &renderer);

/* each frame: */
p3b_render_frame(renderer, seconds, (uint8_t *) pixels, height * stride, stride,
                 P3B_PIXEL_FORMAT_ARGB32_PREMULTIPLIED);

p3b_renderer_free(renderer);                          /* before the model */
p3b_model_free(model);
```

## Contract

- **Errors.** Every fallible function returns a `p3b_status`. On failure,
  `p3b_last_error()` describes the problem; after a success it returns `""`.
  The message is per thread and valid until the next `p3b_*` call on that
  thread. Output pointers (`p3b_model **`, `p3b_renderer **`) are set to
  NULL on failure.
- **No crashes from bad input.** NULL pointers, invalid UTF-8, out-of-range
  enumeration values, short buffers and malformed or hostile model files are
  reported as errors. Internal bugs are caught and reported as
  `P3B_STATUS_PANIC`; a panic never unwinds into C. COLLADA documents are
  capped at 100k nodes and 10M instanced vertices.
- **Ownership.** The caller owns models and renderers and frees them with
  `p3b_model_free` and `p3b_renderer_free`. Both accept NULL. Strings
  returned by the library (`p3b_version`, `p3b_last_error`,
  `p3b_model_warning`) are owned by it; do not free them.
- **Lifetimes.** A renderer borrows its model. The model must stay alive,
  and must not be modified (for example by `p3b_model_add_turntable`), until
  every renderer created from it has been freed. **Free renderers before
  their model.**
- **Limits.** Renderers are at most `P3B_MAX_SIZE` (8192) pixels per side.
  The library requires `panic=unwind`; building it with `panic=abort` is a
  compile error.
- **Resolver callbacks.** `p3b_model_load_memory` calls `resolve` for files
  the model references, such as MTL libraries. Return 0 and set `*data` and
  `*len`, or return non-zero for "not found". The data must stay valid until
  the load call returns; the library copies it. Callbacks must not unwind
  (for example by throwing C++ exceptions) and must not `longjmp` out.
- **Threads.** Models and renderers may be created and used on any thread,
  but a renderer must not be used by two threads at once. Rendering is
  single-threaded and deterministic: the same model, options and time give
  the same pixels.
- **Pixels.** `p3b_render_frame` writes `height` rows of `width * 4` bytes,
  `stride` bytes apart, and never touches the padding beyond each row.
  `dst_len` must be at least `stride * (height - 1) + width * 4`. With
  `P3B_PIXEL_FORMAT_ARGB32_PREMULTIPLIED`, each pixel is a native-endian
  `uint32_t` `0xAARRGGBB` with premultiplied colour, which is Plymouth's
  `ply_pixel_buffer` format.

## Versioning

`p3b_abi_version()` returns the ABI version of the loaded library; the
header defines `P3B_ABI_VERSION`. They match the shared library's major
version, which is bumped on every incompatible change.
